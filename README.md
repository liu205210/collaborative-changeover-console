# 协同换产指挥台

面向电子行业混线换产的仿真应用。在一份计划中安排物料、工装、设备参数、首件检验与质量放行，查看等待原因，并比较异常后的恢复方案。

**[下载完整源码包 source.zip](./source.zip)** · [文件清单与校验值](./manifest.json) · [压缩包 SHA-256](./SHA256SUMS.txt)

本仓库以完整源码包交付，解压后得到 `collaborative-changeover-console/`，包含 67 个源码、配置、说明与测试文件，保留原目录结构。代码可供下载审阅；这不是一个只有演示截图的项目。

所有换产时间与效果均为补充模型下的仿真，OEE 待验证。原始比赛工作簿、运行账本、私有验收夹具和模型凭据不在公开包中。

## 功能

| 页面 | 主要用途 |
| --- | --- |
| 指挥总览 | 汇总已保存计划、A/B/C 对照和校验结果，播放或拖动只读计划时间轴 |
| 换产工作台 | 选择订单，生成三套方案，查看甘特图、人员资源与任务明细 |
| 智能体协同 | 调度、设备、物料、工装、质量、人员共享事实快照，提供有引用的只读问答 |
| 异常演练 | 模拟 AGV 延迟、人员缺席、设备故障、首件失败，对比 R0/R1 恢复方案 |
| 评测中心 | 按集合运行批量评测，保留不可行原因，导出 JSON/CSV |
| 自优化实验室 | 搜索有限的离线准备优先级参数，验证、启用或回滚 |
| 数据与验证 | 核查导入数据、仿真假设、任务依赖、技能、资源和质量门禁 |

## 下载与启动

1. 下载并解压上面的 `source.zip`。
2. 安装 Node.js 18 或以上版本及 npm。
3. 将有权使用、符合字段要求的工作簿放到解压目录中的 `data/upload/赛道数据包.xlsx`。字段说明见包内 `data/upload/README.md`。
4. 在解压后的应用根目录运行：

```bash
npm ci --ignore-scripts
npm --prefix web ci
npm run build:web
npm start
```

打开 `http://localhost:3001`。缺少工作簿时服务仍可启动，但订单列表为空。页面上的“重新导入数据”会重读服务端目录，并不是浏览器文件上传。

首次成功导入后会生成 `data/store/` 保存运行状态。默认规则模式无需大模型；可选模型配置见包内 `.env.example`，真实模型调用尚未验证。
